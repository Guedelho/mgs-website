# MGS — Site institucional

Site da empresa **M GUEDELHO SEREJO - EPP** (MGS), CNPJ 31.747.651/0001-73. Usado como business website para ativação de conta Stripe.

## Estrutura

- `index.html` — página principal (empresa, serviços, produtos, contato)
- `termos.html` — termos de uso
- `privacidade.html` — política de privacidade (LGPD)
- `reembolso.html` — política de reembolso e cancelamento (CDC art. 49)
- `style.css` — estilos compartilhados

## Publicação

Hospedado via GitHub Pages (`Settings → Pages → Source: main / root`). URL pública uma vez ativado:

`https://guedelho.github.io/mgs-website/`

## Antes de publicar

Confirme/atualize os campos abaixo:

- Email de contato em `index.html`, `termos.html`, `privacidade.html`, `reembolso.html` — atualmente `contato@laudai.vet`. Garanta que esse endereço esteja recebendo email (caixa MX configurada).
- Endereço fiscal completo, se o atual da Av. Paulista for um endereço virtual e a Receita Federal exigir outro.
- Datas de "Última atualização" nos termos/políticas se houver mudança de conteúdo.
